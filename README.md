# Zhuozhi Xiong - Academic Website

This is the first static version of the academic homepage.

## Preview locally

From this folder, run any static file server and open `index.html`. For example:

```text
python -m http.server 4173
```

Then visit `http://127.0.0.1:4173/`.

## Before publishing

- Replace the `ZX` portrait placeholder with a professional photo.
- Replace the GitHub placeholder in `index.html` with the final profile URL.
- Replace the Google Scholar placeholder in `index.html` with the final profile URL.
- Add paper PDF, DOI, code, or project links to the publication entries when available.
- Update the CV in `assets/CV_ZhuozhiXiong.pdf` whenever the CV changes.

The page uses only HTML and CSS, so it can be deployed directly with GitHub Pages.
